REST API Documentation

Version 1.0.0

Authentication

All API endpoints require an API key sent in the X-API-Key header.

Generate API Key

POST /api/v1/keys
Content-Type: application/json

{
    "user_id": "your-user-id",
    "name": "My API Key"
}

Endpoints

POST /api/v1/analyze

Analyze an .eml file

POST /api/v1/analyze
Content-Type: multipart/form-data
X-API-Key: your-api-key

File: email.eml

GET /api/v1/history

Get analysis history

GET /api/v1/history?limit=50
X-API-Key: your-api-key

GET /api/v1/scan/{id}

Get a specific scan

GET /api/v1/scan/1
X-API-Key: your-api-key

GET /api/v1/dashboard

Get dashboard statistics

GET /api/v1/dashboard
X-API-Key: your-api-key

DELETE /api/v1/scan/{id}

Delete a scan

DELETE /api/v1/scan/1
X-API-Key: your-api-key

GET /api/v1/health

Health check (no authentication required)

GET /api/v1/health

Testing with curl

# Generate API key
curl -X POST http://localhost:5000/api/v1/keys \
  -H "Content-Type: application/json" \
  -d '{"user_id": "test", "name": "Test Key"}'

curl -X POST http://localhost:5000/api/v1/analyze \
  -H "X-API-Key: your-api-key" \
  -F "file=@email.eml"

curl -X GET http://localhost:5000/api/v1/history \
  -H "X-API-Key: your-api-key"
